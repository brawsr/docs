title: API reference
description: REST and CDP operations for browser sessions, checkpoints, rewind, and fork.
---

The production REST base URL is `https://api.brawsr.io`. Authenticate every REST and WebSocket
request with a project API key:

```http
Authorization: Bearer brawsr_...
```

Each operation page is generated from the published OpenAPI 3.1 contract.

<Callout type="info" title="Run requests from your application">
  This reference is read-only. Use the SDK or your server-side HTTP client to execute requests.
</Callout>
