The production REST base URL is `https://api.brawsr.io`. Authenticate every REST and WebSocket
request with a project API key:

```http
Authorization: Bearer brawsr_...
```

The operation pages are generated from the locally vendored OpenAPI 3.1 contract. The contract is
pinned by version, source commit, release asset digest, and OpenAPI digest before every build.

<Callout type="warn" title="No credential-bearing playground">
  This static site intentionally does not proxy or retain API credentials. Use the SDK or your own
  server-side HTTP client to execute requests.
</Callout>
