These examples are copied from the public [`brawsr/examples`](https://github.com/brawsr/examples)
repository at one pinned commit. The displayed source, its SHA-256 hash, and the
upstream file are checked together in CI, so the documentation cannot silently
drift into a different implementation.

Start with rewind in your preferred language, then move to fork and speculative
branching. Every example chooses an application safe point, reconnects when
browser handles become stale, and closes every session it creates.

<Callout type="warn" title="Recovery has an external boundary">
  Rewind and fork restore captured browser state. They cannot undo an effect a
  website or another external system already accepted.
</Callout>
